## D-003 (2026-07-06) 대상 시장은 한국(KRX) + 미국

두 시장을 모두 다룬다. 이에 따라 모든 시간은 타임존 포함으로 처리하고
(KRX=Asia/Seoul, 미국=America/New_York, 저장은 UTC), KRX 종목코드는
앞자리 0을 보존하는 6자리 문자열로 다룬다.

## D-004 (2026-07-06) 매매 안전 원칙: 기본은 모의투자

실주문은 명시적 플래그(`--live`)와 확인 절차를 모두 거쳐야만 가능하다.
포지션·주문금액·일일 손실 한도를 설정으로 강제한다. 이 원칙은 어떤
경우에도 완화하지 않는다.

## D-005 (2026-07-06) 돈 계산은 Decimal, float 금지

주문금액·가격·손익 계산에 이진 부동소수점을 쓰지 않는다. KRW는 소수점
없음, USD는 소수점 2자리. (예외: 백테스트·통계 분석은 pandas 기반
float 계산을 허용한다. Decimal 강제는 실제 주문 금액 계산에 적용한다.)

## D-006 (2026-07-06) 첫 전략: ETF 모멘텀 로테이션 + 위험 차단 층

첫 자동매매 전략은 ETF 모멘텀 로테이션(코스피200 / 코스닥150 / 미국
S&P500 / 단기채권 후보군에서 모멘텀 상위 1개 보유, 전부 부진하면 현금
대피)으로 한다. 단, 2026년 상반기 폭등 후 기록적 급락(코스피 하루
-9.99%)을 확인했으므로 모멘텀 신호에만 의존하지 않고 다음 두 층을
처음부터 함께 설계한다: ① 변동성 목표(변동성이 커지면 주식 비중 자동
축소) ② 급락 대피(보유 자산이 단기간에 기준 이상 하락하면 신호와 무관하게
현금화). 백테스트는 급락 구간(2008, 2020, 2022, 2026-06)을 반드시 포함해
평가한다.

## D-007 (2026-07-06) 데이터: yfinance 수집 + CSV 캐시

시세 데이터는 yfinance로 수집하고 data/ 폴더에 CSV로 캐시한다. 백테스트는
항상 캐시에서 읽으므로 네트워크가 차단된 환경(원격 AI 세션 등)에서도
동작한다. 데이터 갱신은 사용자 PC에서 scripts/fetch_data.py를 실행한다.
증권사 API 연동은 자동매매 단계에서 별도 결정한다.

## D-008 (2026-07-06) 리밸런싱 밴드 10%p 채택, 급락 대피 -10% 유지

실데이터 백테스트(2020-08~2026-07) 비교 결과로 확정: ① 리밸런싱 밴드
10%p 적용 시 매매 713회 -> 130회로 감소하고 성과는 동일 이상(연 17.35%
-> 17.82%). ② 급락 대피를 -7%로 강화하면 수익·샤프 모두 악화되어 -10%
유지. ③ 변동성 조절을 끄면 샤프 1.27 -> 1.05로 급락하므로 층 자체는
유지하되, 목표 수준(15/20/25%)은 샤프가 동일해 위험 성향 문제 —
2022년 진단 후 사용자와 결정. 미결: 2022년에 전략이 단순보유만큼
잃은(-24.5%) 원인 규명이 설정 확정보다 우선.

## D-009 (2026-07-06) 급락 냉각 15일 + 200일 추세 필터 채택

2022년 진단(diagnose.py)에서 휩쏘 확인: 연 37회 보유 변경, 하루 단위
탈출-재진입 반복. 원인은 ① 급락 대피 기준(10일 고점)이 가격과 함께
내려와 조건이 며칠 만에 자동 해제, ② 하락장 반등마다 모멘텀이 "덜 나쁜
자산"을 재선택. 처방으로 급락 자산 15일 재진입 금지(보유 여부 무관)와
200일 이평선 추세 필터를 추가하고, 1등 부적격 시 차순위 자산을 선택하게
함. 실데이터 검증: 구버전 연 17.34% / MDD -25.01% / 샤프 1.24 →
개선판 20.60% / -20.61% / 1.52 (2022년 -24.5% → -17.8%). 부작용으로
2023년 수익 감소(18.4% → 11.8%, 추세 전환 초기 늦은 재진입)는 수용.

## D-010 (2026-07-06) 변동성 목표 20% (사용자 결정)

15/20/25% 모두 샤프 ~1.52로 동일해 위험 성향 선택의 문제. 사용자가
균형형인 20%를 선택 (백테스트 기준 연 23.9% / MDD -23.0%). 기본값을
0.20으로 변경.

## D-011 (2026-07-06) 진입 문턱 히스테리시스(+2%) 유지

목적은 모멘텀 0 근처 왕복 매매 제거였고 달성됨: 2022년 보유 변경
33 -> 16회, 전체 리밸런싱 87 -> 74회, 하루 단위 진입-청산 왕복 소멸.
성과는 노이즈 범위(연 23.88% -> 23.43%, 샤프 1.51 -> 1.50, 미세 열세
포함)로 판단해 유지 — 실운영에서 주문 수 감소는 모델 밖 슬리피지·운영
위험을 줄인다. 이로써 전략 v1 확정: 연 23.43% / MDD -23.99% / 샤프
1.50 / 리밸런싱 74회 / 평균 비중 67% (2020-08~2026-07, 비용 포함).
